## Build

- **F-tags chosen** from the example questions in prd.md section 4 ([ADR-0005](../adr/0005-narrow-the-rules-corpus.md)): F550, F557, F559, F561, F563, F567, F578, F580, F583, F585, F600, F604, F609, F700. F700 (bed rails) was added because the staff example question is about bed rails.
- `scripts/extract_ftags.py` pulls those tags out of the 926-page Appendix PP and drops the sections written for surveyors (procedures, noncompliance criteria, deficiency categorization). The result is committed in `corpus/ftags/`, so the index can be rebuilt without the PDF.
- `corpus/handbook.md`: Evergreen's own policies, written against the regulation text. Each statement that rests on a federal rule names its F-tag. Key numbers (2 and 24 hours for reporting abuse, written notice before a room change, alternatives and consent before bed rails) were checked against the extracted text, not written from memory.
- `agent/rules.py` and `scripts/build_rules_index.py`: 204 passages, each labelled with its source, embedded locally ([ADR-0015](../adr/0015-local-embeddings-in-memory-index.md)).
- New tool `search_rules`. The system prompt requires citations in the form [F563] or [Handbook: Visiting], forbids citing anything the tool did not return, and leaves care decisions to the care team.

## Error analysis

| Finding | What it means |
|---|---|
| Similarity scores overlap: the weakest in-scope question scored 0.65, while "Can residents have pets?" scored 0.70 | A threshold cannot detect out-of-scope questions. It only removes obvious noise (lunch menu 0.51, wifi password 0.52). The model has to judge, and the evaluation has to check it |
| F600 and F609 make up half the passages | "How do I file a complaint?" retrieved F609 (abuse reporting) first, but F585 and the handbook complaints section were also in the top 5, and the answer cited them |
| First run: "admits unknown" 1/3 | Reading the answers showed **the evaluator was wrong**, not the assistant. Both "failures" said the rules do not cover the question, sent the user to the front desk, and cited a nearby rule while saying it does not cover the case. The check required zero citations, which is stricter than the product rule (prd.md section 6, rule 3). The check was changed to require an honest "I don't know"; whether citations are real is already measured separately. Dataset unchanged, so it stays v1 |

## Carried forward

- When the second provider is available, an LLM judge can check that the cited passage actually supports each sentence, which string checks cannot.
- A future evaluation could compare k=5 with k=3 to see whether fewer, better passages change answer quality.
