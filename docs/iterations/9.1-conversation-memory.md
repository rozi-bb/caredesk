## Build

- Replaced the template graph with one `call_model` node that sends the system prompt plus the whole conversation to `deepseek-flash` (temperature 0).
- State is LangGraph's `MessagesState`: its reducer appends new messages instead of replacing them, which is what gives the model the earlier turns.
- The system prompt states that the assistant cannot look up records yet, so it does not invent schedules or names.
- The graph is built by `build_graph(model)`, so tests can pass a fake model. The DeepSeek model is created on first use, because it refuses to start without an API key and CI has none.
- No checkpointer in code; the Agent Server persists threads ([ADR-0011](../adr/0011-agent-server-handles-persistence.md)).
